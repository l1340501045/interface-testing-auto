# 接口自动化测试与巡检平台

用于管理接口用例、配置执行环境、串联业务场景，并按计划执行巡检和查看失败结果。

规划能力包括可视化请求编辑、cURL 导入、字段断言、变量传递、浏览器请求录制及巡检告警。

项目正在建设中。当前提供可运行的开发底座，尚未提供接口用例、录制或巡检业务功能。

## 开发环境

需要 Docker Desktop、Docker Compose 和 Python 3。业务运行时与依赖均在容器内。

```bash
make dev
```

首次运行会生成仅本机使用的 `.env`，随机生成数据库密码并选择可用端口；已有配置不会被覆盖。控制台会打印前端和后端地址，默认分别使用 15173 和 18080。

前端使用 React、TypeScript、Vite，后端使用 FastAPI，数据库使用 PostgreSQL 16。前后端源码通过只读挂载实现热更新；依赖清单变更由 Compose Watch 重建对应服务。数据库保存在本项目的命名卷中。

`.env.example` 只提供无敏感信息的通用字段。真实 `.env`、密码及本机专属配置不得提交。

## 验证与停止

```bash
make check
make stop
```

检查包括前端类型和构建、后端语法、实际数据库表列中文注释及前后端联通性。停止环境保留数据库卷。需要仅启动容器时可运行 `make up`；源码热更新仍有效，依赖自动重建则需保持 Watch 运行。

源码修改和依赖变更对应不同的更新机制。首次构建需要访问镜像仓库与软件包源；多个工作目录默认使用不同的 Compose 项目名和独立数据卷。
